🛒 Parallel Universe — E-Commerce Platform (UI/UX Focused)

A modern frontend-focused e-commerce platform built with React and Tailwind CSS, emphasizing clean UI, smooth UX, and high performance.

This project is currently frontend-only, using static data, with backend APIs planned for later integration.

___________________________________________________________________________________________________________________________________________________

🚀 Live Vision

The goal is to create an e-commerce experience that feels:

Production-ready

This phase is dedicated to UI & UX perfection before logic complexity.
